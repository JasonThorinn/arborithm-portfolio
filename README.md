# Arborithm-Portfolio
## Arborithm

A software application focused on arboriculture and tree-car workflows.

Arborithm is a softwareArborithm is a software development project that brings together a frontend user interface and a backend service to support arboriculture-related tasks. The project is organized into separate repositories for frontend and backend development.

## Features

- User login and authentication
- Safe Working Load Calculator for determining safe working load and Weight load limit of a rigging system
- Frontend and backend integration
- Interactive user interface

## Technology Stack

- Frontend: React, Typescript, Tailwind CSS, PostCSS
- Backend: Python, Django
- Version Control: Git and GitHub

## Project Structure

- Frontend: Handles the user interface and client-side functionality.
- Backend: Handles server-side logic and application functionality.

## Contributions
